## Handoff

### What changed

- `world/protocol.py`: canonical `Perception`, `BoundaryPerceptionDelivery`,
  `DeferredDecisionTriggers`, `ActionPlan`, `ActionIntent`, `ActionResult`, `ActionFeedback`,
  `StateDelta`, typed targets/parameters, all public vocabularies, `format_delivery_id`, and
  pure shape/order checks. Standalone (new import-linter contract enforces it).
- `world/state.py`: `WorldState`, `ActiveAction` and the physical sub-models (mutable,
  strict, `extra="forbid"`; canonical sort orders validated; `rule_overrides` only `{}`).
- `world/facts.py`: `WorldEvent`, all 25 payload models, `EventType`,
  `PAYLOAD_MODEL_BY_TYPE`, `format_event_id`. Payload is parsed by the model the event type
  names; `resident_moved.from` serializes under its contract name.
- `world/content.py`: `EffectiveConfig` (landed TOML field names), World Rules §1.1 domain
  checks, §1.2 map grammar/position checks, canonical config/map hashes, `WorldContent`
  (re-verifies hashes), `build_world_content` (IO-free).
- `world/ports.py`: `ObservationSample`, `ExposureReceiptUpdate`, `ObservationBatch`,
  `ObservationAccumulator`, `WorldTickCommit`, `WorldEngine` protocol and the frozen
  function signatures; bodies raise `NotImplementedError`.
- `agents/types.py`: DecisionContext, DecisionRequest, DecisionOutcome (discriminated),
  DecisionError, PolicyConfig, OwnProfile, ScriptFixture/ActorScript/IntentTemplate,
  DecisionRecord (agent-interface §5 consistency rules), DecisionTraceManifest,
  ResidentRuntimeState, `build_plan_id`/`build_intent_id`.
- `agents/base.py`: `Policy` and `ResidentRuntime` protocols (replace placeholder `Resident`).
- `sim/ports.py`: `BoundaryObserver` callback protocol.
- `contract/save.py`: backend-only `SavePackage` with `agent_state.runtime_states` and
  root `decision_record_cursor`; cursor/hash consistency checks. Not in `contract.__all__`.
- `events/__init__.py`: read-only re-exports of world facts.
- `persistence/content.py`: `load_world_content(path)` reads TOML + map, validates via world.
- `backend/pyproject.toml`: two added import-linter contracts (world.protocol standalone;
  agents never import contract/persistence/sim). Existing contracts unchanged.
- Tests: `test_content_loader.py`, `test_contract_models.py`, `test_save_and_ports.py`.
- Specs: amendment A1 in `interface-contract-v0.1.md` and `world-rules-v0.1.md`, marked
  `[A1]` in place.
- `docs/spec/open-questions.md`: OQ-004..OQ-007 (see Deviations).

### Deviations

- `docs/spec/open-questions.md` was edited (not in the card's allowed list) because AGENTS.md
  and card §6 require recording assumptions there. Entries:
  - OQ-004: only cue kind `damp_moss`, exactly one cue on the single `M`.
  - OQ-005: need-band cutoffs strictly inside `(min_value, max_value)`.
  - OQ-006: every map row, including the last, ends in LF.
  - OQ-007: payload `action_type`/`failure_code` typed with the vocabularies (contract
    says `string`); unspecified counters nonnegative; goal `priority` any integer.
- World Rules §4.1's "P1 depends only on Perception, ActionPlan…" sentence was also amended
  under A1 item 5, since it repeats the withdrawn IC §2.3 prohibition.
- `ActionIntent` validates its target kind and parameter model against the action table;
  structurally invalid intents cannot be constructed (agents map this to INVALID_PLAN).
- `create_runtime` (agent-interface §2.5) is not declared: it belongs to
  `agents/runtime.py` (P1-06), outside this card's files.
- `WorldState` is mutable (engine-owned); protocol DTOs are frozen. `WorldTickCommit` holds
  whatever snapshot it is given; P1-04 must pass deep copies.
