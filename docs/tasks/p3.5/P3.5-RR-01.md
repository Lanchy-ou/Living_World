### What changed

- Added the `vocab/0.1` registry and an isolated static loader for bound,
  extended TOML packs. The loader normalizes defaults, applies explicit
  replacements and disables, and computes the vocabulary, rule contents,
  rule library and pack SHA-256 identities. The vocabulary pin for downstream
  packs is `57554435492d6f3db83006a4510b292f8b0d1ebc70c3393663fd1a9ad94cf286`.
- Added closed shape and reference checks, branch conservation and source
  bounds, need-rate limits, and proposal validation against the active pack.
  The deterministic report includes slot coverage, equal-specificity overlaps
  and proven unreachable checks.
- Added focused acceptance tests and positive and negative fixtures covering
  the nine validator error codes. Verified the shared v2 initializer byte for
  byte, including its final LF.
