## Handoff

### What changed

Added the strict WAP v0.1 turn, result, perception, boundary report, speech,
agreement and objective event types. The encoder uses canonical UTF-8 JSON and
LF-terminated event records. It sorts collections with protocol keys and
preserves producer order for feedback, received portions and causal references.

Kernel and enabled-verb shape checks report `INVALID_TURN`. The identity-free
model turn schema and its SHA-256 use the enabled verbs' IDs, target kinds and
integer parameter bounds. Added WAP-11, WAP-12 and WAP-13 tests, along with an
import-linter probe that exercises allowed v2 protocol imports and forbidden
world-internal imports.

Gate 2 requested B1 because import-linter skipped the shared `world` package
when checking imports from `world.v2`. The B1 fix explicitly forbids all 23 v1
world modules, including the package initializer, from `world.v2` and its
descendants. The integration test checks that a v2 module importing
`living_island.world.content` breaks the new contract.
