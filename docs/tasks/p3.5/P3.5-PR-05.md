### Phase A

Added the v2 packet-to-submission agent port and per-actor scripted agent.
The coordinator delivers packets, schedules turns, attaches harness-owned
identities to model choices, and passes ordered submissions and
acknowledgements to the world. The in-memory manifest records committed
fallbacks and a terminal stop witness at the frozen boundary. The packet
tests cover eligibility, notification, continue, ordering, fallback
ordinals, rejected submissions, and terminal stops.

Implementation commit `2a7a4bfc77480951df80672028a7a5a244e00493` is based on `bb21352`.
Locked backend sync, `ruff check .`, `ruff format --check .`, `mypy src`,
and `lint-imports --no-cache` passed (13 contracts).

in one session with command-scope Git long paths and a fresh Windows base directory.
