## Handoff

### What changed

- Added the `compat-v1` pack with the v1 materials, archetypes, placements, rules, comparison tables, and failure-code table.
- Added a single CR-011 registry for the pinned TOML and map digests and all four byte substitutions. The loader reads TOML directly and binds typed values through RR-01. It returns the validated pack, effective config, map rows, code table, and manifest hashes.
- Derived the per-need bounds from the v1 work durations and deltas. The zero-growth binding omits the periodic rule, the source, and all corresponding phase offsets.
- Checked code-table coverage against the validated rule checks and RR-01's unreachable report. Added 27 compatibility tests for load behavior and the pinned identities.
- Gate 2 rework moved `compat_regrow_fruit` to a separate `[[rule]]` template. The loader includes it only for positive growth. OQ-P3.5-CT-02 records why the loader binds the whole rule array.
- Added a production manifest comparison for P2 seed 1007489817 against its PR-03 fixture and asserted that `P2_SEEDS` equals the matrix fixture seed set. Removed the redundant seed type guard and kept registered-seed admission.
