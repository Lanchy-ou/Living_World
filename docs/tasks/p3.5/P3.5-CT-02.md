## Handoff

### What changed

- Added the `compat-v1` pack with the v1 materials, archetypes, placements, rules, comparison tables, and failure-code table.
- Added a single CR-011 registry for the pinned TOML and map digests and all four byte substitutions. The loader reads TOML directly and binds typed values through RR-01. It returns the validated pack, effective config, map rows, code table, and manifest hashes.
- Derived the per-need bounds from the v1 work durations and deltas. The zero-growth binding omits the periodic rule, the source, and all corresponding phase offsets.
- Checked code-table coverage against the validated rule checks and RR-01's unreachable report. Added 25 compatibility tests for load behavior and the pinned identities.
