   `store` plus a regrowth world rule for both (§3.1 there).
2. ADR 0011 D2 says record values are strings or integers; the memory model
   also uses a boolean flag and `null` (§1 there).
3. ADR 0010 D2 says about 10 starter rules; the draft has 13 verb rules and 9
   world rules (owner decision CT-D10).
4. ADR 0013 D7 keeps the rule-based policy as the fallback "as in P3". In the
   starter pack it runs without the legacy bridge, which the frozen protocol
   limits to the compatibility pack, and reads visible feedback instead
   (owner decision DL-D10).

   a process entity that anyone can finish (rule representation §5.4).
6. The rule representation's draft list named a `freshness` property; it is
   withdrawn so that fruit shows no age (owner decision CT-D7).
