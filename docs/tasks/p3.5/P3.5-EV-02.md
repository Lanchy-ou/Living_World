**Acceptance and evidence.**

- **EV-04.** Test all five learning flags in evaluation §3.3 and the mixed case. Relate own failures to the actual rule, reject an unrelated failed pot for the axe, require both observed phases for watched learning and valid sent citation plus a saved content check for told credit. Preserve unchecked cases. Follow earlier-period records and evidence across waking periods, including two periods on one calendar day. A first correct attempt with no qualifying evidence is prior knowledge. Stable instance IDs link the adopted choice to the objective success and the exact earlier revisions.
- **EV-05.** Show each self-found skill hypothesis with its creator, prediction, sources and the code-counted attempts, matched expected phenomena, ratio and distribution where defined. Join evidence by attempt and immutable revision. A resident who learns from an actual snapped vine cord scores correctly despite deceptive appearance. Preserve zero observations, unknown evidence and supplied attempts separately. A fallback action or delayed fallback result earns no resident learning credit.
- **EV-23.** Include per-period morning/turn exposure and every attempted consolidation, including selection-only and guarded omissions, failed/abandoned change sets, and the committed supplier. Propagate only through the recorded `supplies_period` relationship. Distinguish retrieval from actual use. Display the first decision dispatch per record and turn, the before/after store versions, original waking period and calendar day. A retrieved record omitted from all dispatches leaves continuity unchanged. Label exposed periods/turns separately from natural context effects.
- Use all six call kinds and failed, retried and no-dispatch outcomes. For each resident/day/turn show full vs sent tokens, pressure, log growth, guard omissions, cache hit/miss, latency, fallback and input/output spend from recorded attempts. Show measured tokens/share per sent manifest section, including framing/schema accounting as recorded. Attribute monetary section estimates transparently from measured shares and recorded input charges, showing output and unassignable cost separately; provider-level cache and tariff data determine the measured total. Display unavailable usage as null with reason. Reconcile available totals with ledger call IDs; fake execution has zero paid spend. Keep estimates out of the spend ledger.
- A second export produces the same IDs, values and hashes. Test the ordinary viewer import with fixture shards, show named source links and evidence, and verify that displayed metrics match the exported values. Missing qualifying skills or actual prior-day dispatches must be visible as observed results.
