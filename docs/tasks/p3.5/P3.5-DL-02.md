## Handoff

### What changed

The context package opens a prefix from the resident's profile, enabled verbs and MM-01 store projection. It prepares a separate morning call through DL-01 and records its disposition. A short wake reuses the prior prefix. An exhausted caller produces an empty selection and an unfit request returns the measured floor to sim.

Sim supplies the filtered physical packet, original member positions and joins to the resident's own adopted choices. The log assigns period-local entry IDs, writes canonical entries and rendered fragments by SHA-256 and retains the heard utterance verbatim. The current state renders the delivered explored map and carries the current intention's local ID and revision. Dialogue tracks addressed exchanges and unanswered proposals until gap expiry or period release.

`WorkingContext.prepare_decision` assembles the prefix, log and current state for either decision stage. `WorkingContext.freeze` gives MF the period entries and the last rendered state with its measured pressure line. Subsequent sleep deliveries append to the live log. Sim owns scheduling, origin filtering, retries and period transitions.
