### Deviations

An initial focused run exposed two missing pieces of synthetic pack metadata,
and mypy required a type annotation on the crossing accumulator. The first
full collection exposed a v1 test filename collision. The fixture, annotation,
and v2 test filename were corrected before the recorded runs. The implementation
commit was created while the full suite ran, with identical engine and test files.

The c50beac settlement stub leaves successful sleep starts and on_interrupt
execution at a test seam. Tests use the settlement callbacks to exercise the
physiology boundary without the concurrent EN-02 implementation. Phase 2
need effects are exercised with explicit ProgressNeeds inputs. The shared tick
driver currently invokes the two hooks with just its context.

### Open questions

- For integration, mark successful sleeps with start_sleep during phase 2 and
  preserve sleep awareness through phase 5 of their last tick. Capture phase 2
  need openings and rule IDs and pass the same ProgressNeeds mapping to
  physiology, stops, and the EN-05 crossing input. EN-05 owns delivery filtering
  and woke reports. The EN-02 branch owns actual interruption effects.
- The frozen starter spec names fatigue coefficients without a concrete TOML
  nesting. The test extension uses the named keys in [physiology]. RR-01
  currently validates the table shape but leaves coefficient types unchecked.
  Validate the chosen layout and coefficient types at pack load before adding
  a starter pack, then project them into engine configuration.
- Ending a sleep with a higher-priority living stop clears sleep awareness.
  The implementation reserves early=true for WOKEN. This is observable if a
  future pack enables exhaustion_stops on a sleep rule.
- The agent-side K composition check and exact compatibility proof remain in
  their owning cards.
