### Goal and non-goals

P3.5-EN-08 cut 24.8% of the time per tick. A reviewer profile of the
121-tick prefix on the EN-08 revision (54 s under cProfile) still puts about
80% of run time in `deepcopy`:

- `sim/v2/runner.py` `Runner.advance`, about 14 s. `World.pending_packets`
  already returns detached packets. The runner copies each packet again for
  the delivery callback and again for the decision callback, and it
  deep-copies each submission.
- `world/v2/engine/tick.py` `World.step`, about 12 s. `step` deep-copies the
  whole `WorldState` as its transaction. That includes `static_map`, the rule
  `library` and other values that no tick changes.
- The frozen v1 `agents/runtime.py`, about 17 s. This is out of scope: v1
  modules are frozen.

Goal: remove copies that protect nothing, and keep every isolation that the
specs and approved rulings require. These are the detached packet delivery
of OQ-P3.5-PR-05, the atomic tick (a refused boundary leaves the world
unchanged), and the isolation of committed choices from later callback
edits. A copy that remains needs a reason in a comment.

Non-goals: changes to v1 modules, to the protocol models, or to settlement
semantics.

### Deliverables

For each removed copy, name the writer and the readers of the value, and
the boundary that still detaches any mutable data. For the tick
transaction, either share the values no tick mutates (for example through a
`deepcopy` memo, as EN-08 did for tile lists) or show why a copy is still
required. Record the timing pair and the campaign result in the handoff.

### Acceptance (positive, negative, edge, determinism)

1. **Isolation.** These must hold, using the existing PR-05, PR-06 and
   EN-08 controls plus a focused regression only for an uncovered path:
   - a delivery or decision callback that mutates nested data in its
     packet cannot change the runner's held packet, `turn_reasons`,
     `check_binding`, the journal or another consumer's view;
   - a refused boundary (`InvalidTurn`) leaves the world state and the
     pending deliveries unchanged;
   - a callback edit after a submission is committed cannot change that
     submission.
2. **Timing pair.** Run the 121-tick prefix (`--through 120`, `--jobs 1`,
   case `acceptance-production-base-2600456787`) on a clean detached
   checkout of the base and on this branch, back to back on the same host.
   Report milliseconds per tick for each.
3. **Equivalence.** Run the 20 registered acceptance cases through PR-07's
   command on this branch, `--through 1008 --jobs 4`, under the host lock.
   All 20 must match at every boundary with zero declared exceptions.

descendant. Test it with a reachable mutation. If removing the tick copy
needs a settlement change, stop and report to Claude Code instead.
