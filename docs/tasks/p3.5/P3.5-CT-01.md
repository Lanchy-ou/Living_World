## Handoff

### What changed

- Added the `engine-test` fixture, its 7 × 5 map and two residents, and a load
  test using `living_island.world.v2.rules` and the pinned `vocab-0.1.toml`.
- CT-14 checks closed-term coverage on the loaded pack and verifies all nine
  validator codes against one-edit negative variants. A repeated load gives
  the same pack, rule hashes, and slot coverage report.
- EN-22 discovers authored archetype, material, and rule IDs from every pack
  under `content/packs` and reports matching whole IDs in `world/v2` Python
  source with file and line. The base has no real packs. The planted tests
  exercise all three ID categories and verify that longer identifiers pass.
