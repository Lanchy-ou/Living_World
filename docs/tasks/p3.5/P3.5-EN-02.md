## Handoff

### What changed

Implemented v2 act matching, deterministic chance, physical reservations and
atomic branch settlement. The tests use the shared `pack`, `setup`, and
`world` fixtures and cover the three Round 3 cases and the rule-pack extension
with its conservation refusal.

Gate 2 B2 uses the loader's `Rule.specificity` for candidate ranking. The
rebase onto EN-04 preserved the B2 patch as `13544b1` (originally `4c92d5b`).
The rebase completed without conflicts.

Gate 2 B1 delegates sleep start from `settle.py` to `physiology.start_sleep`.
The tick collects opening need values and rule IDs in an actor-indexed
`ProgressNeeds` mapping and passes that same mapping to the required phase 5
and phase 6 physiology arguments. EN-04's physiology tests load a real sleep
rule from their pack extension and exercise actual settlement. The integration
tests cover one combined need event, a rule-driven crossing into the critical
band that stops sleep with `WOKEN`, and the first asleep boundary at `t + 1`.
