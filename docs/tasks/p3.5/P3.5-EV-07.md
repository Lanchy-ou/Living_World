All paths are relative to `backend/src/living_island/` except `scripts/`, `frontend/`, CI and tests. First publish an **exact, per-file** disposition and reverse-import inventory in this card's PR. Authorize only named v1-specific files in the signed/allocated inventory. New proof goes in `backend/tests/v2/v1_retirement/**`.
