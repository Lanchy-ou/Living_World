## Handoff

### What changed

Added the `projection/0.1` reader and writer, the frozen v1 extractor, and
`scripts/gen_v1_projections.py`. The archive contains 20 S2 m6/base
acceptance runs and 140 development runs through tick 1,008, 58 scripted
projections, and four exact substitutions from the CR-011 registry.
Each run records the v1 source commit, raw and effective content hashes,
seed and generator version. Fixtures use canonical JSON in timestamp-free
gzip files. The complete fixture tree is 7,468,357 bytes (7.12 MiB),
within the 50 MiB D4 limit.

The 160-run matrix generation took 6,933.1 seconds with 16 workers. The
scripted generation took 45.3 seconds while matrix runs were active.
The full byte-for-byte check took 6,028.9 seconds, including the
scripted fixtures and all 160 v1 runs.
