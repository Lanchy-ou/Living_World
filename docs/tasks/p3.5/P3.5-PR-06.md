### What changed

Implemented protocol §11.2 using the frozen rule planner. The compatibility
host maps v1 intents to current world turns, joins talk outcomes under the
original v1 intent, projects v2 sight and carried items into legacy receipts,
and applies the v1 interruption and trigger ordering. Its private checkpoint
carries the delivery cursor, receipts, deferred triggers, queue, intent
bindings, policy state, undelivered bridge outcomes and delayed-stop matches.
The bridge is admitted only for its pinned `compat-v1` pack. Visible mode
derives private transitions from public feedback without installing the
bridge. The model and memory delivery ports receive independent, filtered
packets. The fallback test exercises those ports with a scripted model
stand-in and day-log/recall sinks.
