## Handoff

### What changed

The offline exporter verifies the pinned source files before and after reading them and writes a bounded `ia/0.1` archive. It rebuilds full, candidate, floor and dispatched requests from their recorded parts, exports independent morning calls, and preserves provider usage and its missing-data reasons. Packet entries retain their ordered member paths. Store snapshots, immutable revisions, skill evidence, consolidation effects and analyst relabel flags can be followed independently of the current resident store. Saved choice checks include the exact cited text sent to the model.

From the repository root, use absolute paths for all four arguments.

```sh
uv run --directory backend python -m living_island.analysis.v2.export RUN VERIFIED_MANIFEST REPLAY FRESH_DIRECTORY
```

`RUN` contains `resident.sqlite`, `packets/0.json` and subsequent numbered batches. Supply `content-checks.json` there when its digest is present. The separate verified manifest uses the `FinishedRun` input type. It contains `status="finished"`, run ID, arm, pack ID/hash pairs, resident/profile pairs, final tick, replay and audit SHA-256 digests, packet digests in boundary order and the nullable content-check digest. Supply the exact matching ReplayBundle file separately. The destination must be fresh and outside the run. The index is written last. A failed export can leave part files there, so use a new destination on retry.

In the existing viewer, open that ReplayBundle, choose **Open inspection…**, select `index.json` and **all** numbered JSON files together, then choose **Decision debug**. Select a decision, call, packet, evidence write or period snapshot. **Show … at tick …** selects the resident on the replay. The memory browser links relabel flags to their version and the disclosed records. Existing P3 inspection uses the same import button.

The proposed wave-8 Python interface is `living_island.analysis.v2.shards.InspectionArchive.open(directory)`. Its `index` holds the typed references. `read(ShardRef)` verifies and loads one logical shard. `revision(resident_id, RevisionRef)` resolves an exact version and content hash, returning `None` for an absent revision.
