## Reproduction

Run at the M6 integration base `a22360d0ef4c39f08c887d463c7576022873c605` from the
repository root. Use fresh output paths for a repeat. The serial command below
reproduces the matrix with the complete registered acceptance list.

```sh
uv sync --directory backend --locked
uv run --directory backend python ../scripts/p2_experiments.py batch --batch-id p2-05-accept-all --seed-list acceptance --case s2-default:m6:base
```

The executor ran ten batches in parallel, using `--seeds <two comma-separated seeds>`
and distinct `--batch-id` values. The per-case manifest, metrics and logs are under
`runs/p2/<batch-id>/`. P2-03 supplies the fixed length of 1,008 ticks and exports
`replay.json` in each case directory.

The first registered seed also supplies the checkpoint comparison. The independent
checkpointed run and its two derivatives live under `runs/p2-05-m7/`.

```sh
uv run --directory backend python -m living_island run --config ../content/worlds/default.toml --policy rule-based --seed 2600456787 --ticks 1008 --checkpoint-every 144 --out ../runs/p2-05-m7/checkpointed
uv run --directory backend python -m living_island resume --checkpoint ../runs/p2-05-m7/checkpointed/checkpoint-0000000144.json --source-run ../runs/p2-05-m7/checkpointed --ticks 864 --out ../runs/p2-05-m7/continuation
uv run --directory backend python -m living_island reexecute --source-run ../runs/p2-05-m7/checkpointed --out ../runs/p2-05-m7/recorded
uv run --directory backend python tests/fixtures/p1_06/check_m2.py ../runs/p2-05-m7/checkpointed ../runs/p2-05-m7/continuation ../runs/p2-05-m7/recorded
```

For the acceptance case with the same seed, compare the two JSONL streams and
the final canonical world with the checkpointed run. The supplemental runs
test determinism and recovery separately from the 20-case acceptance count.
