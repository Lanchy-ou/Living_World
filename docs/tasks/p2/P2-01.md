## Handoff

### What changed

Implemented CR-004. Fresh rule runs share one validated `RuleParams` value in their
tick-zero `PolicyConfig`. The CLI accepts the approved switch and parameter-file
combinations. The wait stub records issued-intent references through the runtime commit
hook. The hook discards pending rule state when a decision produces an error.

Restore validates all Rule Policy §7.2 checks. It verifies rule lineage through the
requested save, ancestor saves and joined decision prefix. The root checkpoint must bind
to the verified initialization event, and policy identity is checked across the chain.
Recorded re-execution preserves source decision provenance. Tests cover RJ-1 through
RJ-8, the commit transaction, CLI combinations and P1 checkpoint bytes at ticks 0 and 4.
