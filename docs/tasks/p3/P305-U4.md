are outside the counter's certified ASCII/basic-Han domain. The counter
correctly uses the full UTF-8 byte bound for the span. This does not measure
the provider's actual tokenizer count for the blocked requests. Tick 1's
retained goals, owned intents and recalled experience contain these characters.
The earlier synthetic tape's admission result did not cover this live
model-output and recall path.
