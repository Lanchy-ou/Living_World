## Executor interface freeze and file ownership

Shared DTO shapes are the accepted M8 schemas, implemented separately from legacy
models. The initial skeleton fixes the following Python names and seams before any
parallel implementation. Validation is completed by each file owner without changing
these field shapes; any contract change returns to the lead and frozen-spec process.

- Memory exports DeliverySourceRef, DecisionSourceRef, OwnedIntentRef, OwnStateData,
  FeedbackData, AcceptedDecisionData, ExperiencePayload/Record/State, RetrievalQuery,
  RetrievalResult and RetrievalProfileId. Pure canonical_bytes/canonical_sha256 and
  build_experience_id/build_decision_id live in memory.p3_types; no agents import there.
- Agent DTOs and ProviderAdapter, DecisionBudgetPort, AttemptJournalPort,
  FallbackAdapter and ResidentRuntimeP3 protocols live in agents/p3/types.py and
  ports.py. Protocols construct no runtime, authority or provider. All money is
  integer micro-CNY; BudgetCaps.micro_cny and PricingPin.currency=CNY are explicit.
- initial_experience(owner_id); ingest_experience(state, delivery, *, run_id);
  capture_accepted_decision(state, run_id, decision_id, decision_ordinal, plan,
  attached_goal_id, *, max_plan_actions) return new validated ExperienceState values.
- retrieve(state, query, retrieval_profile, *, selector=None,
  expected_implementation_sha256=None) returns complete rank IDs and selected copies.
  An injected RetrievalSelector declares retrieval_profile and implementation_sha256
  and exposes retrieve(state,query). The pure layer checks both against the admitted
  profile/pin. Outer retained-input verification belongs to P3-03/05; no filesystem
  access or registry/plugin mechanism is added to memory. P3-06 owns the alternate
  algorithm in test code; P3-02 supplies the typed seam and refuses unbound fixtures.
- cognition provides initial_goal_state(), validate_goal_state(state,*,actor_id),
  apply_goal_change(state,change,*,actor_id,tick),
  advance_goal_evidence(delivery,owned_intents,state,*,run_id), attached_goal_id(state)
  and validate_proposal(proposal,request,config)->(ActionPlan,CognitiveDelta).
- assemble_context(perception,cognitive_state,profile,*,purpose="live",selector=None,
  selector_sha256=None) returns ContextAssembly; purpose is live/fake/recorded-fake.
  A fixture binding is accepted only in the corresponding verified fake lane.
- prompts provides build_model_action_contract() and
  render_provider_request(assembly,request,config,template:bytes). characters provides
  load_profiles(explicit_paths) and resolve_identity(*,actor_id,display_name,profile_id,
  initial_direction,profiles)->(ResidentIdentity,IdentitySource).
