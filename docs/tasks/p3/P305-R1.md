## Handoff

### What changed

CR-007 adds one separately approved replacement to the existing smoke envelope.
The launcher requires a canonical committed registration plus the exact approved
registration and original-allocation digests. It explicitly authorizes, then
separately enrolls the replacement. Run, resume and finalize verify the issued
binding. The original pilot approval and completed allocation are read-only.
A replacement record and independent guard retain the same identity and
issuance state under the existing enrollment lock. Both must show issuance
before the first provider preflight. The only interrupted issuance state that
can advance has an issued primary record, an initializing guard and an intact,
unused replacement authority with its lock.

The authorization is a local operator action after owner approval. The store
checks its canonical durable records, with the same single-host storage model
as the original pilot. A coordinated rollback of the entire repository-wide
authority and its guard is outside supported recovery. When the guard survives,
joint loss inside the authority root and rollback of only the primary record
fail closed.
