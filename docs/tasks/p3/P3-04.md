- `DeepSeekResponsesAdapter` implements the frozen pure request preparation and
  response mapping. It verifies retained wire bytes before counting/sending;
  authentication is header-only. The one-shot stdlib HTTPS transport has no SDK,
  implicit retries, redirects, conversation state or tools. It caps raw reads at
  B-07 plus one sentinel and enforces a total deadline across connection, headers
  and body reads. Timeout evidence retains the observed prefix without accepting
  late output; absent bodies remain distinct from confirmed empty bodies.
- `FakeProviderAdapter` accepts only local `FakeReply` values. Scripts, logical
  elapsed times, sent bytes and cap-plus-one reads are deterministic. The exact
  `fixture-wire-bytes/0.1` count includes the entire prepared schema and framing.
- `FrozenRuleFallbackAdapter(config).decide(request, state)` projects only the
  specified legacy own perception/identity fields and executes one disposable
  instance of the frozen rule policy. It returns a staged plan/private successor.
  `return_to_llm(state)` freezes the old rule state; later re-entry clears stale
  commitment/issued references, expires only elapsed deadlines, and preserves
  unexpired failures/local entries, cue impressions and learned capacity. All
  decisions use the actor's global ordinal. `InvalidFallbackPlan` preserves the
  caller's prior state and leaves the single wait substitution to the coordinator.
- Production input counting deliberately raises `INPUT_COUNTER_UNAVAILABLE` in
  both count and complete before transport access. No exact hosted Flash-1017
  tokenizer/framing correspondence was established, so no heuristic or arbitrary
