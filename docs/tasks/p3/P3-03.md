### What changed

- [Resident runtime](../../../backend/src/living_island/agents/p3/runtime.py) implements
  atomic packet ingestion, cold restoration, bounded staged decisions, one-time
  publication, copied state export and exact recorded execution. Attempts use only
  injected provider/fallback ports. Classified failures retain terminal usage and
  provenance; unexpected programming/IO errors stop the interval. The factory is
  re-exported explicitly without changing the legacy factory's behavior.
- [P3 coordinator](../../../backend/src/living_island/sim/p3.py) provides opt-in
  `run_p3`, `resume_p3` and `reexecute_p3` Python entry points. It preserves actor
  order, active actions, queued intent IDs, deferred triggers and pre-ingest pending
  packets. It publishes every boundary, including tick zero. Replay recomputes
  cognition/context/selector manifests, copies original audit rows, and checks final
  checkpoint/trace bytes with provider, fallback and authority access sentinels.
  Replay uses standard suffix-only segments inside its output container;
  `P3RunResult.output` and `ancestors` identify the final artifact directory and its
  verified ancestor locators. There is no new CLI or provider implementation.
- [Save contracts](../../../backend/src/living_island/contract/p3_save.py) and
  [persistence](../../../backend/src/living_island/persistence/p3.py) implement the
  approved 0.2 save/origin/trace envelopes, five linked logs, normative
  `p3-inputs.json`, source-pinned retained inputs and strict provenance checks.
  Publication flushes log prefixes, prepares the authority head, durably publishes
  the checkpoint and only then finalizes the head and debit settlement. Windows
  publication uses write-through rename; POSIX also flushes directory entries.
- [Allocation authority](../../../backend/src/living_island/persistence/p3_allocation.py)
  separates create-once enrollment from execution. Stable OS locks, generations,
  current checkpoint ownership and pre-dispatch reservations prevent duplicate
  grants across copied outputs, stale/current restores, contention and crashes.
  The six approved pilot slots total exactly `150000000` micro-CNY. A clean current
  head reuses its existing enrollment; neither a checkpoint nor a new output
  directory supplies another grant or requests another approval.
- Interrupted spend requires an immutable offline recovery origin and retained
  evidence. Recovery imports each authority reservation once at full reserved cost
  or greater reported usage, permanently disables calls and survives interrupted
  import/publication. Recorded replay uses only immutable mirrors/evidence and
  never enrolls, locks, admits, settles or refunds authority capacity.
