## Handoff

### What changed

- `contract/replay.py`: `ReplayBundle`, `DisplayFrame` and their parts, as replay-frontend §2.2.
  All models derive from the canonical `ProtocolModel` (strict, `extra="forbid"`, frozen);
  `replay_schema_version` is `Literal["0.1"]`; `events` reuses the canonical `WorldEvent`.
  Imports only `world.facts` and `world.protocol` (no `world.state`, no `sim`).
  Cross-field errors start with a stable rule slug (`frame_ticks:`, `event_range:` ...).
  `contract/__init__.py` is untouched and `__all__` is unchanged, so the legacy combined
  schema/TS output keeps the same bytes.
- `scripts/gen_types.py`: also writes `frontend/src/api/generated/replay.schema.json`
  (JSON Schema 2020-12, rooted at `ReplayBundle`, definitions in `$defs`, pydantic field order)
  and the `gen:types` script emits `replay.ts` from it.
- `frontend/tests/replay-schema.smoke.mjs` + `test:schema` script; `ajv@8.17.1` (exact pin;
  8.20.0 exists but was not used; no release-age override was needed).
- Shared fixtures `backend/tests/fixtures/replay/`: `valid.json`, 62 files in `invalid/` and
  `build.py` (the builder; a test fails if committed files drift). A `.gitattributes` there
  keeps `*.json` byte-exact on Windows.
- `backend/tests/unit/test_replay_contract.py` (77 tests).
- `docs/spec/interface-contract-v0.1.md`: amendment A2 (below). OQ-009 to OQ-013 appended.
- `.github/workflows/ci.yml`: one step, `pnpm --dir frontend run test:schema`, in the
  `frontend` job after the build.
