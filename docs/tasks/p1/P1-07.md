## Handoff

### Implementation

- The CLI uses the P1-06 boundary observer to append one canonical display frame to
  `frames.jsonl` per committed boundary. Projection selects only the public display fields
  and derives the event slice from the snapshot cursor and callback event count.
- The exporter verifies the completion manifest and event log, checks the spool against
  the final tick, and validates the full bundle before publishing `replay.json` atomically.
  The bundle uses canonical UTF-8 JSON with one final LF, matching the fixture convention
  authorized in OQ-010. `resume --export-replay` directs the caller to re-execution.
- OQ-023 is closed by `event_payload__type_mismatch`, generated by `build.py`. The existing
  backend and browser fixture tests both reject it.
- P1-06 R-02 is closed. The storage tests now use `stage_resume_output` directly and finish
  their writes inside the staging context. The bootstrap helper and its private writer-path
  assignments were removed.

  checks the spool's frame count, JSON and canonical bytes, and the bundle's cross-field rules
  (tick sequence, event ranges, sort orders, coordinates, tree and resident identities). It
  never compares any frame's values with committed state. The capture path is correct, but a
  damaged spool that is still self-consistent is published. Probe: I changed
  `residents[2].health` in the last line of `frames.jsonl` from 70 to 71, keeping the line
  canonical, and `export_replay` published `replay.json`. The run directory holds a final
  checkpoint, and the trace manifest holds `final_world_sha256`. Projecting the last frame from
  the final checkpoint's world would close this at no cost. The brief only forbids repairing or
  inventing frames, so this is a hardening note.
