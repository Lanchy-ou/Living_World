## Handoff

### What changed

- `frontend/src/replay/`:
  - `validate.ts`: JSON parse, Ajv2020 (strict) against the generated schema, unknown-version
    check, payload/type agreement, then the cross-field rules. Returns a result, never throws on bad
    input and never modifies it.
  - `crossField.ts`: browser mirror of every backend cross-field rule group, same slugs and order.
  - `store.ts`: `ReplayStore` (frames indexed by tick, current tick, play state, speed, selection,
    filters, camera); `canon.ts`: UTF-8 ordering, event-ID format and a pure SHA-256 for `map_hash`
    (`crypto.subtle` is not available on every file page); `clock.ts`: §4.2 formulas and night test;
    `loader.ts`: file, drag-and-drop and bundled example; `types.ts` re-exports the generated types.
- `frontend/src/render/`: `drawFrame.ts` (pure drawing from the current frame; `computeSprites` is the
  testable geometry), `camera.ts` (fit, zoom, clamped pan, follow), `theme.ts`, `Legend.tsx`,
  `MapCanvas.tsx`, `view.ts`.
- `frontend/src/controls/`: playback bar, camera controls, load controls.
- `frontend/src/panels/`: pure view-models (`residentView`, `resourcesView`, `eventView`) and their
  panels. `frontend/src/debug/`: error details and raw event JSON.
- Tests and fixtures: `frontend/tests/validator.test.mjs`, `viewer.test.mjs`, `lib/`, and
  `fixtures/handmade/` (hand-made, see its README). Node's built-in test runner with native TypeScript
  stripping is used, so no dependency was added.
- `package.json`: `test` script only. `ci.yml`: one step, `pnpm --dir frontend run test`.
- No backend, generated, spec (other than OQ log) or `gen_types.py` change.

Backend fixture acceptance, run from the repo root (script reproduced here; it lives outside the repo):

```python
# uv run --directory backend python -I check_fixtures.py
from pathlib import Path
from pydantic import ValidationError
from living_island.contract.replay import ReplayBundle
d = Path("../frontend/tests/fixtures/handmade")
valid = ["move-and-gather", "contention", "death-drops-pickup", "edge-frame0-only", "edge-all-dead"]
invalid = ["edge-unknown-terrain-symbol", "edge-unknown-version", "edge-events-out-of-order",
           "edge-missing-frame", "edge-broken-json"]
for n in valid:
    ReplayBundle.model_validate_json((d / f"{n}.json").read_bytes())      # must not raise
for n in invalid:
    try:
        ReplayBundle.model_validate_json((d / f"{n}.json").read_bytes())
    except ValidationError:
        continue
    raise SystemExit(f"unexpected accept: {n}")
```

Result: `ACCEPT` for `move-and-gather` (7 frames, 18 events), `contention` (5, 18), `death-drops-pickup`
(8, 14), `edge-frame0-only` (1, 1), `edge-all-dead` (3, 7); `REFUSE` for the five invalid edge files; exit 0.
