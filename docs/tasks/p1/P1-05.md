  1. Canonical encoding (IC §6.3): one encoder for snapshot, event and decision bytes; UTF-8
     without BOM, LF, sorted keys, compact separators, ensure_ascii=False, allow_nan=False,
     integral numbers only; JSONL records end with exactly one "\n". If it must live outside
     world/content.py, it delegates to it.
  2. Event validation (events/, read-only, IC §3.1): run_id, event_id format via
     format_event_id, tick monotonic, seq_in_tick contiguous from 0 per tick, tick 0 starts
     with world_initialized, payload type matches type, caused_by_event_ids reference only
     already-emitted IDs (forward and unknown references rejected). Validates; never allocates.
  3. JSONL writers/readers for events.jsonl and decisions.jsonl (AI §5): append-only, records
     written in the order given; readers verify versions, run_id, canonical bytes and
     contiguous per-actor decision_ordinal.
  4. SavePackage write/read (IC §5, AI §6): atomic write (temp file in the same dir, flush,
     fsync, os.replace) to a path that must not already exist; an existing save is never
     overwritten. Read verifies save_schema_version, canonical bytes, config/map hashes
     against the retained inputs, and the checkpoint consistency below.
  5. Checkpoint history validation (carried from P1-01a G2-R2-01): each runtime's
     next_decision_ordinal is bounded by the boundaries that actor could have ingested by
     the saved tick; a dead resident's latest_perception_tick and ordinal agree with its
     recorded death boundary (no ingest at or after the death tick). Persisted-file
     rejection tests for both reviewer cases (tick-4 save with 5 decisions for one actor;
     dead cursor equal to death tick). Use the spec's death/ingest rules (AI §2.1, §3.2,
     §6; WR §5.4 phases 1, 5, 6); if a bound is ambiguous, log OQ-026+ and choose the
     smallest reversible check.
  6. Verified run inputs (AI §4.2, §4.3, §5, §6): config.json and map.txt retained in
     each run dir and re-verified by hash; ScriptFixture loading with canonical SHA-256
     identity and per-actor ActorScript slices; decision-trace.json manifest read with
     version, counts, file hashes and final_world_sha256; per-actor recorded-decision
     slices for RecordedPolicy. Source run files are opened read-only and never mutated.
  7. Resume output (IC §5 A1, AI §6): an output-directory guard (distinct from source,
     contains no run artifacts) and writers for post-checkpoint events/decisions plus
     resume-origin.json {source_run_id, checkpoint_tick, checkpoint_sha256, event_cursor,
     decision_record_cursor}. A test proves source-run bytes and mtimes are unchanged.
  8. Version refusal everywhere (no migration): save, event, decision, trace, script.
Acceptance (positive, negative, edge, determinism):
  - identical input gives identical bytes (events, decisions, save, manifest); a hypothesis
    round-trip test: write -> read -> write is byte-identical;
  - forward and unknown causal references are rejected; seq gaps, duplicate IDs and wrong
    run_id are rejected;
  - a bad version, hash, non-canonical JSON, NaN/float, BOM, CRLF or missing final LF fails
    with a clear typed error naming the file and field;
  - an existing save or output directory with artifacts is refused; an interrupted atomic
    write leaves no partial target file;
  - resume writes only post-checkpoint records into a distinct directory and never touches
    the source run; a changed script or trace identity is refused (AI-13 input side);
  - both G2-R2-01 cases are rejected from persisted files;
  - import-linter: events/ imports neither sim nor persistence; no world change.
Verification commands: all AGENTS.md commands; pytest via
  `-p no:cacheprovider --basetemp=<scratch>` on Windows if the default temp dir fails.
