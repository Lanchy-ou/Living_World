## Handoff

### What changed

- Added read-only event sequence validation for world-allocated IDs, tick and sequence
  order, payload types and causal references. Added canonical append-only JSONL readers
  and writers for events and decisions, with typed file, field and line diagnostics.
- Added atomic checkpoint creation and validation against retained config and map identities.
  G2-R2-01 is covered by persisted-file tests for both an excessive decision ordinal and
  ingestion at the recorded death tick.
- Added retained config and map IO, script and trace identity verification, and isolated
  actor-local input slices. Trace manifests check log bytes and counts and carry the final
  world hash for the P1-06 re-execution comparison.
- Added continuation output with origin metadata and checkpoint-seeded log writers. The
  resume tests cover causal references into the source prefix, ignoring later source
  bytes, chained resume, and preservation of source file bytes and mtimes.
- Added 53 regression cases, including a Hypothesis test that checks byte-identical
  write/read/write for events, decisions, saves and manifests across 25 generated examples.

### Deviations

- The executor fixed fixture trigger and line-number expectations and made the new tests
  self-contained after a collection-order failure. The successful Windows pytest run
  used a pre-created ignored scratch parent after a temp directory setup failure.
- The same-directory reservation serializes concurrent checkpoint publishers through
  persistence. Abrupt process termination can leave a reservation sidecar.
- P1-06 owns CLI orchestration, ancestor-prefix discovery and re-execution against the
  recorded final world hash. Gate 2 is pending independent review.
