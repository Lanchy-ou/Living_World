# Living Island — P3.5 implementation plan v0.1

> **Draft (2026-11-15).** Only the system index and naming rules are filled in.
> Scope, milestones, gates and tasks follow as each system's discussion converges.

## 0. Purpose

P3.5 runs alongside the remaining P3 work (P3-06, P3-07). It builds fuller,
extensible versions of the two core systems:

- the world as a data-driven rule system (materials with properties, generic
  verbs, transformations as content);
- the resident agent built around memory (the context window is a view assembled
  from several kinds of memory for each decision).

Acceptance targets the preconditions for emergence: information spreads and is
believed or doubted; rules are discovered, remembered and taught; artifacts persist
and are used by others; commitments hold across days.

The rule discovery layer (C) is not a P3.5 system. It is a design constraint on
systems 1 and 2 and becomes its own phase after the rule system (B) runs.

## 3. Known dependencies

- System 1 comes first: every other system depends on it, and it changes a frozen
  contract (change-request process, P1 plan §7).
- System 1 and system 2 are designed together: the protocol shape depends on how
  rules are represented.
- System 5 can start early, except "learned skills", which depends on system 2.
- System 7's action form is fixed by system 1.
- System 4 is content only: the engine never contains code for one recipe.

## 4. Naming rules

1. One fixed subject slug per system, used in ADR, spec and task names.
2. ADR: `docs/adr/NNNN-<slug>.md`, no version, no phase. A later reversal is a new
   ADR that names the one it supersedes.
3. Spec: `docs/spec/<slug>-vX.Y.md`. A new subject starts at `v0.1`; a new version
   is a new file and the old one is not edited. No "v2" in file names.
4. Phase appears only in plans and tasks: `docs/plans/p3.5-…`, `docs/tasks/p3.5/`.
5. Task IDs: `P3.5-<system code>-<NN>`, for example `P3.5-PR-01`; branch
   `task/P3.5-PR-01-<slug>`. The dot keeps them apart from P3-05 sub-task IDs such
   as `P305-R1`.

## 5. Exploration lane

Decided in ADR 0014 D4: `explore/<slug>` branches, runs under `runs/explore/`,
notes in `docs/explore/<slug>.md`, no Gate 2, no changes to frozen contracts or
specs, and promotion through a normal task before anything reaches `main`.
